# Amazon_India_Dashboard
Saffire_IQ Platform Project 1

## 📌 Project Overview
This project analyzes Amazon India sales data using Excel.

## 🎯 Objectives
1. Overall Sales & Profit Performance
2. Category & Product Performance
3. Order Status & Revenue Loss
4. Payment, Fulfillment & Geographic Analysis

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers

## 📊 Features
- KPI Metrics (Sales, Profit, Orders)
- Monthly Trend Analysis
- Top Products & Categories
- Returns & Cancellation Analysis
- Payment & State-wise Insights

## 📂 Files Included
- Amazon_India_Dashboard.xlsx
- dashboard.png

## 🚀 How to Use
Download the Excel file and explore the Dashboard sheet.
